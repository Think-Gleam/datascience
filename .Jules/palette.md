## 2024-05-18 - Missing ARIA Labels on Icon Buttons\n**Learning:** In shadcn/ui and custom components across this repository, `<Button size="icon">` combined with lucide-react icons consistently lacks accessible names (aria-labels). Screen readers read these simply as "button".\n**Action:** Add explicit `aria-label="Action description"` to all icon-only button components to ensure clear narration.
